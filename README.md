## Проекты

### [vtscan — проверка файлов через VirusTotal API](https://github.com/ph4nt0m11/vtscan)

CLI-инструмент на Python. Сначала локально вычисляет SHA256 и ищет существующий отчёт VirusTotal; загружает файл только при отсутствии записи, затем ожидает результат анализа.

**Почему выбран такой подход:** меньше лишних загрузок, экономия API-квоты и более бережное обращение с файлами. API-ключ хранится вне исходного кода. Отсутствие обнаружений не считаю доказательством безопасности файла.

### [pentest-english — тренажёр технического английского](https://github.com/ph4nt0m11/pentest-english)

Офлайн-инструмент на HTML/JavaScript для работы с терминологией информационной безопасности: карточки, упражнения и практические фразы.

## Как я подхожу к задачам

**Наблюдение → гипотеза → проверка → поиск причины → решение → контроль результата.**

Для меня важно понимать, почему выбран инструмент, что именно доказывает результат и какие ограничения остаются. В обучении разделяю «знаком», «практиковал» и «могу применить самостоятельно».
